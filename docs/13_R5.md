## 1. Lattices with Clifford order O_E
- Under (H), ⟨1, ε⟩ ≅ (O_E, N_{E/K}). The basis 1, θ with θ = (μ/2)√−2 and θ² = −ε gives N(x + yθ) = x² + εy².
- Its Clifford order is O_K[θ] = O_E (Lemma 10.1).
- A binary O_K-lattice whose Clifford order is O_E is an O_E-module of rank 1 (IMPORTED, standard; L2.2). So it is M_𝔄 = (𝔄, N/n) for a fractional ideal 𝔄 and some n ≫ 0 with N(𝔄) = nO_K, hence [𝔄] ∈ A.
- Conversely, every such M_𝔄 is classically integral (Theorem 10.2(a)).

## 2. The genus

**Theorem 13.1 (PROVED; IMPORTED inputs: the module structure above, local class field theory for quadratic extensions, the Hilbert product formula).**
- (a) G = gen⟨1, ε⟩ = {M_𝔄 : [𝔄] ∈ A}.
- (b) M_𝔄 ≅ M_𝔅 properly ⇔ [𝔄] = [𝔅]. So G has exactly |A| = h(−8D)/2 proper classes (Theorem 11.1(b)).
- (c) For every M ∈ G the proper automorphism group O⁺(M) is {±1}. M_𝔄 has an improper automorphism iff [𝔄]² = 1. So G has (|A| + |A[2]|)/2 isometry classes, and M_𝔄 ≅ M_{𝔄̄} by an improper isometry.

*Proof.*
1. **Proper isometries.** These are O_K-linear maps of determinant 1, and SO(E, N) = E¹ = {w : N(w) = 1} acts by multiplication. An isometry of the forms that maps 𝔄 to 𝔅 sends (𝔄, N/n) → (𝔅, N/n′) and is z ↦ wz with w𝔄 = 𝔅 and N(w) = n′/n.
   - So M_𝔄 ≅⁺ M_𝔅 ⇒ [𝔄] = [𝔅].
   - Conversely, if 𝔅 = w𝔄, then N(w)n/n′ is a totally positive unit ε^k. Replacing w by wθ^{−k} (N(θ) = ε) gives an isometry. This is where (H) is used.
2. **Local isometry.** At a prime v of K, 𝔄_v = z_vO_{E,v}, so M_{𝔄,v} ≅ (O_{E,v}, c_v·N) with c_v = N(z_v)/n ∈ O_{K,v}^×.
   - (O_{E,v}, cN) ≅ (O_{E,v}, N) iff c ∈ N(O_{E,v}^×).
   - At unramified v the norm is onto the units.
   - The only finite ramified prime is 𝔭 (𝔡_{E/K} = 𝔭⁴, Theorem 11.1). There (c_𝔭, −2)_𝔭 = (n, −2)_𝔭 = ∏_{v≠𝔭}(n, −2)_v = 1, because:
     - n ≫ 0 at the real places;
     - v(n) = v(N𝔄) is even at the inert v.
   - So c_𝔭 is a local norm, and N(w) ∈ O_𝔭^× forces w ∈ O_{E,𝔭}^×.
   - Hence every M_𝔄 with [𝔄] ∈ A is in G.
   - Conversely, the Clifford order is a local invariant, so every M ∈ G has Clifford order O_E and is some M_𝔄 by §1. This proves (a).
3. **Automorphisms.** O⁺(M_𝔄) = {w ∈ O_E^× : N(w) = 1}.
   - Under (H), O_E^× = {±1}·θ^Z (unit index 2, Theorem 11.1(a)) and N(θ^k) = ε^k, so O⁺(M_𝔄) = {±1}.
   - Improper isometries are z ↦ wz̄ and map M_𝔄 to M_{w𝔄̄}, with [w𝔄̄] = [𝔄]^{−1} because 𝔄𝔄̄ is principal.
   - So M_𝔄 ≅ M_𝔄 improperly iff [𝔄] = [𝔄]^{−1}. ∎

**Corollary 13.2.**
- (i) **Shyr's H** (CONSISTENT). The proper class number of the genus is h(−8D)/2. L2.2 transcribes Shyr's H = (h_E/h_K)·2^{1−t}/[U_E^0 : U_K^0]; with h_E/h_K = h(−8D) (Theorem 11.1(a)), this gives the same value for t = 1 (the finite ramified primes: 𝔭 only) and [U_E^0 : U_K^0] = 2 (Hasse's Q = 2 under (H)). The conventions of the original are not re-checked.
- (ii) **Siegel weights are uniform.** All |O⁺(M)| = 2, so the Siegel-weighted genus average of any class invariant equals the plain average over the h(−8D)/2 proper classes.
- (iii) **Without (H)** (PROVED as in steps 1–2; D ≡ 3 mod 4, N(ε) = 1, 𝔭 not principal). (O_E, N) is not free (Steinitz class [𝔭]⁻¹), so it lies in a different genus from ⟨1, ε⟩. Its genus has |A|·[O^{×,+} : N O_E^×] = (h(−8D)/4)·2 = h(−8D)/2 proper classes, because ε is a local norm at 𝔭 by the same product formula. This case is not needed below.

## 3. The genus sum (L5.5 made precise)
For [γ] ∈ I(K)/K^{×2}, let r(γ) := #{c ∈ A : some integral 𝔅 ∈ c has 𝔅𝔅̄ = γ₁O_E for a member γ₁ of [γ]}.

**Theorem 13.3 (PROVED).** Σ_{M∈G} s□(M) = Σ_{c∈A} n(c) = Σ_{[γ]} r(γ), the sum over proper classes. Moreover:
  N_E(K) ≤ Σ_{M∈G} s□(M) ≤ Σ_{γ ∈ I(K)/(O^×)²} Σ_{m | N(γ)} χ₋₈(m) ≤ 2ι·max_{n ≤ D} d(n),
and the genus average is
  avg_G s□ = (2/h(−8D))·Σ_{[γ]} r(γ).
For p prime the middle sum is Σ_f ν(f) (Theorem 11.3), so avg_G s□ is exactly the quantity "avg" of docs/11_R3.md §4.

*Proof.*
- s□(M_c) = n(c^{−1}) (Theorem 10.2(c)) and c ↦ c^{−1} permutes A. Exchanging the order of summation gives Σ_c n(c) = Σ_{[γ]} r(γ).
- Lower bound: each [γ] counted by N_E has r(γ) ≥ 1.
- Upper bound:
  - r(γ) is at most the number of pairs (member γ₁ mod (O^×)², 𝔅 with 𝔅𝔅̄ = γ₁O_E);
  - the number of such 𝔅 is Σ_{m|N(γ₁)} χ₋₈(m) ≤ d(N(γ₁)) (Lemma 11.2), with N(γ₁) ≤ D (Dress–Scharlau);
  - there are 2ι indecomposables mod (O^×)². ∎

This is L5.5 with the divisor factor made explicit: max_α #{ideals of E of norm (α)} = max Σ_{m|N(α)} χ₋₈(m) ≤ D^{o(1)}. The bound is far from sharp. The data give avg_G s□ ≈ 3.3·ι/√p (docs/11_R3.md §4), against the bound's 4ι·D^{o(1)}/h(−8D).

## 4. Proper vs improper, and the order O[√−δ] vs the maximal order
- **Proper vs improper** (Theorem 13.1(c)).
  - Proper classes ↔ A.
  - Improper isometry identifies c with c^{−1}; s□ and n are invariant under it (n(c) = n(c^{−1})).
  - So "the genus" counted with improper equivalence has (|A| + |A[2]|)/2 classes. For p prime, A ≅ Cl(−8p)², and |A[2]| = 1 when h(−8p)/2 is odd.
- **Proposition 13.4 (PROVED; trace obstruction).** For a classically integral binary M with det class δ and E = K(√−δ), the Clifford order C₀(M) lies in {z ∈ E : Tr_{E/K}(z) ∈ 2O_K}.
  - Proof: C₀(M) is spanned over O_K by 1 and the products vw (v, w ∈ M), and Tr(vw) = 2B(v,w) ∈ 2O_K.
  - Hence:
    - **det class 1 (E = K(i), D ≡ 3 mod 4).** O_E ∋ (1 + i√D)/2, of trace 1. So **no classical lattice has Clifford order O_E**. The classical genera in det class 1 are governed by the Picard groups of non-maximal orders (O_K[i] ⊆ C₀ ⊊ O_E), not by Cl(E). Shyr's maximal-order count does not apply to them directly, and the O_E-ideal lattices are only norm-integral (docs/10_R2.md §3, L8.6).
    - **det class 2 (E = K(√−2)).** Tr O_E = 2O_K (Lemma 10.1), so there is no obstruction, and ⟨1, ε⟩ has the maximal order. This is why the theory of §§2–3 (and all of R2/R3) lives in det class 2.
- **Other genera in det class 2.** Integral lattices with Clifford order O_E but N(𝔄) = n𝔫₀ (𝔫₀ a product of inert primes, Cor. 10.3(i)) form further genera G_{𝔫₀}, with s□ ≤ n_{𝔫₀}(c). Lattices with non-maximal Clifford order O_K + 𝔣O_E form further genera again. Neither is needed for the lower bounds. The equality S_E(K) = max_{G} s□ is CERTIFIED only for D = 43, 691, 5419, 12511, 17539, 19231 (Cor. 10.3(iii)).

## 5. Average vs maximum (CERTIFIED / EMPIRICAL)
**Independent check of Theorem 13.1 + 10.2(c) + 11.3 (CERTIFIED; `python3 scripts/r5_genus.py p …`).**
- Every M ∈ G is unimodular, hence a maximal integral lattice. Under (H), s□(M) is even, so s□(M) > 0 forces a frame.
- So R1's complete enumeration (all frames, no Galois reduction, maximal isotropic glue) meets every M ∈ G with s□ > 0.

- So the maximum exceeds the genus average by a slowly growing factor. Bounding the average (Theorem 13.3) bounds the maximum only up to the number of classes, which is useless.

**Consequence for L5.3 / L5.5.**
- The genus average is explicit and, empirically, of order ι/√p (≍ log p for h(Q(√p)) = 1).
- The maximum is a few times larger, so it is not controlled by equidistribution alone (as L5.3's caution said).
- Since avg_G ≤ max_G ≤ S(K,2), a uniform bound on S would bound the genus average too. In the data the average itself grows (EMPIRICAL: ≈ 3.3·ι/√p, and the mean of max_G grows like 2.8·ln p), so the evidence against boundedness does not rest on rare records.
- Unboundedness is still OPEN; the gaps are (G1) and (G2) of docs/11_R3.md §5. By Theorem 13.3, a lower bound for the average amounts to (G1) + (G2).
