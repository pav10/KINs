# 14 — R6: the rank-1 core — indecomposable squares and T(K) → ∞

Roadmap R6 (ledger L5.1). Decide sup_K T(K), where
  T(K) := max over square classes C ∈ K^×/K^{×2} of #((I(K) ∩ C)/(O^×)²),
the largest number of unit-square orbits of indecomposables in one square class, i.e. #{ξO : γξ² ∈ I(K)} maximised over γ. It decides whether the count mod (O^×)², s_u, can be uniform.

**Answer.**
- sup_K T(K) = ∞ (**PROVED**, Theorem 14.2): T(Q(√(n²+3))) ≥ 1 + 2⌊log₉(2n)⌋. So s_u is not uniform in any rank r ≥ 1 (Corollary 14.5). Only the count mod K^{×2} can be uniform, as CLAUDE.md standard 4 assumed.
- At the same time T(K) ≤ 3s (**PROVED**; sharpened to T(K) ≤ 2s in R7, Corollary 15.2(d)): like S(K,2), T is controlled by the period.
- In the data T grows much faster than the proved logarithm. The record T₁ = 57 at D = 87151 (s = 720) comes from fields with many small principal ideals (EMPIRICAL).

Code:
- `scripts/r6_squares.py`: the witness test, T₁ in O(s), the D = n² + 3 family.
- `tests/test_r6.py`.

Throughout, D ≡ 2, 3 (mod 4) is squarefree and O = Z[√D]. A sketch for D ≡ 1 (mod 4) is in §4.

## 1. An exact witness test for indecomposability

**Lemma 14.1 (PROVED; converse IMPORTED).** Let α = x + y√D ≫ 0 with gcd(x, y) = 1 and y > 0, so σ₂(α) = x − y√D > 0. Let m ∈ [1, x] with m·y ≡ −1 (mod x).
- If m·σ₂(α) < √D, then δ := (b√D − m)/(2√D) with b = (1 + my)/x is totally positive, lies in the codifferent, and has Tr(δα) = 1. Hence α is indecomposable.
- Conversely, if α is indecomposable then m·σ₂(α) < √D. This uses the IMPORTED fact that every indecomposable has such a δ (Kala–Tinková, t₂ = 1).

*Proof.*
- **Parametrisation.** O^∨ = (2√D)⁻¹Z[√D]. Writing δ = (a + b√D)/(2√D) gives Tr(δ(x + y√D)) = bx + ay, and δ ≫ 0 ⟺ b√D > |a|.
- **Solutions.** The solutions of bx + ay = 1 are a ≡ −m (mod x), b = (1 − ay)/x.
- **The cone condition.**
  - For a ≥ 1 (with y ≥ 1) we get b < 0, so the cone condition fails.
  - For a = −c ≤ 0 it reads c·x < √D(1 + cy), i.e. c·σ₂(α) < √D. This is monotone in c, so the smallest admissible c = m decides.
- **Indecomposability.** If α = β + γ with β, γ ≫ 0, then Tr(δβ), Tr(δγ) are positive integers, so Tr(δα) ≥ 2. ∎

The test is exact over the integers (m²x² < D(1 + my)²) and needs one modular inverse. It agrees with the CF orbit test (`lattice.indecomposable_test`) on every primitive α ≫ 0 with N(α) ≤ D and y < 30 for the first 40 fields (test_window_criterion_matches_cf_test). Earlier spot run: 3031 elements over 2 ≤ D < 400, 0 mismatches.

**Corollary 14.1′ (PROVED).** Every primitive α ∈ Z[√D], α ≫ 0, with N(α) < 2√D is indecomposable.
- Indecomposability and primitivity are unchanged under multiplication by the totally positive fundamental unit η. Replace α by αη^k (or its conjugate) with k large.
- After that replacement, y > 0 and σ₂(α)/x → 0.
- The admissible c form the interval [1, √D/σ₂(α)). The integers 1, …, x all lie in it iff x·σ₂(α) < √D.
- Now x·σ₂ = N(α)·x/σ₁ = N(α)/(2 − σ₂/x), using σ₁ = 2x − σ₂. This is < √D for k large exactly when N(α) < 2√D.
- So c = m is admissible. ∎ (For α itself the guaranteed threshold is only N(α) < √D.)

(Compare Dress–Scharlau, IMPORTED: indecomposables have N(α) ≤ D.)

**Lemma 14.3 (PROVED).** For ξ = p + q√D with gcd(p, q) = 1, the square ξ² = (p² + Dq²) + 2pq√D is primitive ⟺ gcd(N(ξ), 2D) = 1.
- *Proof.*
  - p² + Dq² is odd ⟺ N(ξ) is odd (check D mod 4).
  - An odd prime r dividing both p² + Dq² and pq must divide p, hence D (since r ∤ q), hence N(ξ). Conversely, an odd prime r | gcd(N(ξ), D) divides p, hence both coordinates.
  - Checked on random coprime pairs (test_primitivity_criterion; an earlier run used 2·10⁵ draws). ∎

## 2. T₁ — the class of 1 — exactly
Let T₁(K) := #{ξO : ξ² ∈ I(K)}, the fibre of the class of 1.

**Proposition 14.4 (PROVED; Lagrange and Dress–Scharlau IMPORTED).** With the CF data of √D (complete quotients (P_k + √D)/Q_k, convergents α_k = p_k + q_k√D, |N(α_k)| = Q_{k+1}):
  T₁(K) = 1 + #{0 ≤ k < s : 1 < Q_{k+1} ≤ √D, gcd(Q_{k+1}, 2D) = 1, and α_k² passes Lemma 14.1}.

Consequently:
- (a) 1 + #{primitive principal ideals 𝔞 ≠ O with gcd(N𝔞, 2D) = 1 and N(𝔞)² < 2√D} ≤ T₁(K) ≤ s.
- (b) T(K) ≤ 3s for every square class. [R7: ≤ 2s, since the rank-1 lattice below is classical, Theorem 15.1.]

*Proof.*
- **Formula.** ξ² ∈ I forces ξ² primitive and N(ξ)² ≤ D (Dress–Scharlau), so |N(ξ)| < √D. By Lagrange's theorem ξ is then ±(unit)·α_k for some k in one period. The α_k with k < s are pairwise inequivalent mod units, and Q_s = 1 is the unit.
- **(a)** The lower bound is Corollary 14.1′ with Lemma 14.3. The upper bound counts k.
- **(b)** Fix γ₀ ∈ I ∩ C and let 𝔟₀ be the largest ideal with 𝔟₀² | (γ₀).
  - Every γ₀ξ² ∈ I has (ξ)𝔟₀ integral (indecomposables are primitive), so the class is exactly the set of indecomposable values of the integral rank-1 lattice (𝔟₀⁻¹, γ₀x²).
  - The per-face lemma L1.4 in rank r = 1 gives ≤ ½τ₂ = 3 values per edge, and L1.5 gives s edges mod (O^×)². ∎

**Checks (CERTIFIED).**
- The formula agrees with the exact square-class computation (`complete.FieldData`) for all 612 squarefree D ≡ 2, 3 mod 4, D < 1500; test_T_bounds_and_T1 re-checks D < 300.
- In 447 of those 612 fields the class of 1 is a largest fibre.
- The formula costs O(s) operations, against O(ι·…) for the full square-class computation.

## 3. T(K) → ∞

**Theorem 14.2 (PROVED; squarefree values IMPORTED).** Let n ≥ 2 be even with 3 ∤ n and D = n² + 3 squarefree. Then
  T(Q(√D)) ≥ T₁ ≥ 1 + 2·#{j ≥ 1 : 9^j < 2n} = 1 + 2⌊log₉(2n)⌋.
Since n² + 3 is squarefree for a positive proportion of n (Estermann 1931; Ricci 1933 — IMPORTED), sup_K T(K) = ∞ and T(K) ≫ log D along the family.

*Proof.*
- **The prime above 3.** ξ = n + √D has N(ξ) = −3. D ≡ 1 (mod 3), so 3 splits, and (ξ) = 𝔮 is a prime above 3.
- **Primitivity.** ξ^j generates 𝔮^j, so it is primitive (𝔮′ ∤ 𝔮^j). gcd(3^j, 2D) = 1 because D is odd and 3 ∤ D, so ξ^{2j} is primitive by Lemma 14.3.
- **Indecomposability.** ξ^{2j} ≫ 0 and N(ξ^{2j}) = 9^j < 2n < 2√D, so Corollary 14.1′ applies. The same holds for its conjugate.
- **Distinct orbits.** The 2j elements generate the distinct ideals 𝔮^{2i}, 𝔮′^{2i} (1 ≤ i ≤ j), so they lie in distinct (O^×)²-orbits. Together with 1, all lie in the class of 1. ∎

**Checks.**
- Exact for all admissible n < 400, where each ξ^{2j} passes the witness test (test_family_n2_plus_3).
- `r6_squares.py family 1000` covers all admissible n ≤ 1000.
- The bound is far from tight: n = 100 gives T₁ = 11 (bound 5) and n = 1000 gives T₁ = 27 (bound 7). Other small principal ideals contribute: norms 11, 19, 31, 33, 37, 43, … at n = 1000.

**Corollary 14.5 (PROVED).** For every rank r ≥ 1, sup over real quadratic K and integral rank-r M of s_u(M) is ∞. Here s_u counts represented indecomposables mod (O^×)².
- The rank-1 sublattice ⟨1⟩ ⊂ ⟨1, …, 1⟩ already represents T₁(K) distinct orbits ξ², all in one class mod K^{×2}.
- This resolves L5.1: the unit-square count is not uniform already in rank 1. It does not affect s□ = 1 for rank 1.

## 4. How large is T? (EMPIRICAL / HEURISTIC)
- **Records of T₁** over squarefree D ≡ 2, 3 mod 4 up to 2·10⁵: see §5.
- By Proposition 14.4(a), T₁ is squeezed between counts of small principal ideals:
  - below, the primitive principal ideals of norm < (2√D)^{1/2} = √2·D^{1/4} coprime to 2D;
  - above, the principal ideals of norm ≤ √D.
- For h(K) = 1 the lower count is ≍ D^{1/4}·L(1, χ_{4D}). So T₁ ≫ D^{1/4−ε} on any infinite set of class-number-one fields. HEURISTIC; the gap is that infinitely many such fields are not known, which is Gauss's problem again (cf. docs/11_R3.md (G1)).
- Unconditional polynomial growth of T along an explicit family is OPEN. Families with one small principal prime (like Theorem 14.2) give only ≍ log D.
- **D ≡ 1 (mod 4).** Z[ω] has O^∨ = (√D)⁻¹O and the analogue of Lemma 14.1 carries a parity condition on (a, b). The data for D ≤ 1500 (e.g. T = 15 at D = 1441, with norms of ξ = 2, 3, 4, 5, 6, 12) behave the same way. Not written out: OPEN in this form.
