S(K,2) → ∞ by Corollary 10.3(ii).

## 1. Setting and notation
- D ≡ 3 (mod 4) squarefree, K = Q(√D), O = Z[√D], E = K(√−2), with (H): 2ε ∈ K^{×2} (docs/10_R2.md).
- Subfields of E: k1 = Q(√−2) and k2 = Q(√−2D).
- Gal(E/Q) = {1, σ, ρ, τ}, where ρ is complex conjugation (fixes K), σ fixes k1, and τ = σρ fixes k2.
- h(−N) is the class number of discriminant −N. The narrow class number is h⁺(K) = 2h(K), since N(ε) = +1.
- CF of √D: complete quotients x_k = (P_k + √D)/Q_k, a_k = ⌊x_k⌋, period s (even), convergents p_k/q_k, α_k = p_k + q_k√D.
- The indecomposables modulo ⟨ε⟩ are β_{j,t} = α_{j−1} + tα_j for j even, 0 ≤ t < a_{j+1}. There are ι = a_1 + a_3 + … + a_{s−1} of them.
- **Lemma 11.0 (PROVED, elementary).** N(β_{j,t}) = Q_j + 2tP_{j+1} − t²Q_{j+1}, and Q_{j+1}·N(β_{j,t}) = D − u² with u = Q_{j+1}t − P_{j+1}.
  - From p_k² − Dq_k² = (−1)^{k+1}Q_{k+1}, p_{k+1}p_k − Dq_{k+1}q_k = (−1)^{k+1}P_{k+2} and P_{k+1}² + Q_kQ_{k+1} = D.
  - So all norms are ≤ D and come from small integers. No element of size ε is needed.
- **(H) test (PROVED).** (H) ⇔ x² − Dy² = ±2 is solvable ⇔ 2 ∈ {Q_k}.
  - (⇐) If N(μ) = ±2, then μ²/2 is a totally positive unit ε^j, and j is odd because 2 ∉ K^{×2}.
  - The second equivalence is Lagrange's theorem, since |±2| < √D.
  - Agrees with the R2 test on all 4055 fields D ≤ 20000.
- N_E(K) := #{[γ] ∈ I(K)/K^{×2} : γO_E = 𝔅𝔅̄ for an integral 𝔅}, and n(c) as in §10.1.

## 2. Results and proofs

**Theorem 11.1 (PROVED; inputs IMPORTED: Herglotz, class field theory).** Assume (H). Then:
- (a) h(E) = h(K)·h(−8D).
- (b) n(c) = 0 unless c ∈ A := ker(N_{E/K}: Cl(E) → Cl⁺(K)), and |A| = h(−8D)/2.
- (c) Consequently S(K,2) ≥ max_c n(c) ≥ (2/h(−8D))·Σ_c n(c) ≥ 2N_E(K)/h(−8D).

*Proof.*
- (a) Herglotz's formula for the imaginary biquadratic field E (w_E = 2; Herglotz 1922, Lemmermeyer 1994) gives h(E) = ½·Q·h(K)h(−8)h(−8D), where Q = [O_E^× : μ_E O_K^×].
  - The unit θ = (μ/2)√−2 of §10.1 satisfies θ² = −ε and is purely imaginary, so θ ∉ ±O_K^×. Hence Q = 2.
  - Also h(−8) = 1.
  - Without (H), Q = 1: Q = 2 ⇔ −ε ∈ E^{×2} ⇔ 2ε ∈ K^{×2}.
  - CERTIFIED against PARI for all 4055 squarefree D ≡ 3 mod 4, D ≤ 20000 (both cases) and all 4808 primes ≤ 10^5.
- (b) Support:
  - N_{E/K} maps principal ideals (z) to (z z̄), with z z̄ ≫ 0, so it is well defined into Cl⁺(K).
  - If 𝔅𝔅̄ = γO_E with γ ≫ 0, then N_{E/K}(𝔅) = γO_K, which is trivial in Cl⁺(K).
  - Size: E/K is ramified above 2. The relative discriminant has norm d_E/d_K² = 256D²/16D² = 16, so 𝔡_{E/K} = 𝔭⁴. Hence E ∩ H⁺_K = K, and N: Cl(E) → Cl⁺(K) is onto (class field theory).
  - So |A| = h(E)/h⁺(K) = h(K)h(−8D)/(2h(K)).
- (c) The first inequality is Corollary 10.3(ii). Pigeonhole over the |A| classes in the support gives the second. Each [γ] counted by N_E hits at least one class, which gives the third. ∎

Compared with L8.3 (≥ N_E/h(E)), this gains the factor 2h(K). The class number of K disappears from the pigeonhole bound; it survives only inside ι (§4).

**Lemma 11.2 (PROVED).** Let γ ∈ I(K). The number of integral 𝔅 ⊆ O_E with 𝔅𝔅̄ = γO_E is Σ_{m | N(γ)} χ_{−8}(m) = ½·r_{x²+2y²}(N(γ)). In particular, γ counts in N_E ⇔ N(γ) is represented by x² + 2y² ⇔ every prime ≡ 5, 7 (mod 8) divides N(γ) to an even power.

*Proof.*
- **Primitivity.** Indecomposables are primitive: γ = mγ′ with m ≥ 2 gives γ = γ′ + (m−1)γ′.
- **Consequences of primitivity:**
  - no inert prime of K divides γ;
  - above a split q at most one 𝔮 divides γ (else q | γ);
  - 𝔭 (above 2) and 𝔡 | q | D divide γ at most once.
  - So the local factors of γO_K correspond one-to-one to the prime powers q^a ∥ N(γ).
- **Local count.** The number of 𝔅 with 𝔅𝔅̄ = 𝔮^aO_E is Σ_{i ≤ a} χ_{E/K}(𝔮)^i, with:
  - χ_{E/K}(𝔮) = (−2/q) = χ_{−8}(q) for 𝔮 of degree 1 over q ∤ 2;
  - χ_{E/K}(𝔭) = 0, since 𝔭 ramifies in E.
  - This is the local factor of Σ_{m|N(γ)} χ_{−8}(m).
- CERTIFIED against PARI half-norm ideals (`r2_classes.half_norm_ideals`) for every rep in 6 fields, and against PARI's N_E in 64 fields. ∎

**Theorem 11.3 (PROVED; inputs IMPORTED: genus theory).** Let D = p ≡ 3 (mod 4) be prime, so (H) holds. Let Φ := N_{E/k2} restricted to A. Then:
- (a) Φ is a bijection from A onto the principal genus Cl(−8p)² of the form class group of discriminant −8p.
- (b) For c ∈ A, n(c) = ν(Φ(c)), where ν(f) := #{[γ] ∈ I(K)/K^{×2} : some indecomposable γ₁ ∈ [γ] with N(γ₁) ∈ x² + 2y² has N(γ₁) represented by f}.
- (c) ν(f) = 0 for f ∉ Cl(−8p)². Hence the multisets {n(c)}_{c∈Cl(E)} and {ν(f)}_{f∈Cl(−8p)} agree, and **max_c n(c) = ν*(p) := max_f ν(f)**.

*Proof.*
1. **Galois action on Cl(E).** For L ⊂ E with [E:L] = 2, c·c^g = j_L(N_{E/L}(c)), where g generates Gal(E/L).
   - Cl(k1) = 1 gives c^σ = c^{−1} on all of Cl(E).
   - For c ∈ A, N_{E/K}(c) is trivial in Cl(K), so c^ρ = c^{−1}.
   - Hence c^τ = (c^ρ)^σ = c, and j_{k2}(Φ(c)) = c·c^τ = c².
2. **Injectivity.** E/k2 is ramified above 2 (d_E/d_{k2}² = 4), so N_{E/k2}: Cl(E) → Cl(k2) is onto and |ker N_{E/k2}| = h(E)/h(−8p) = h(K).
   - h(Q(√p)) is odd for p prime (genus theory, IMPORTED). So ker N_{E/k2} has no 2-torsion.
   - If Φ(c) = 1, then c² = 1 and c ∈ ker N_{E/k2}, hence c = 1.
3. **Image.** For c ∈ A, pick 𝔅 ∈ c integral and prime to 2p.
   - N_{E/Q}(𝔅) = N(β) with βO_K = N_{E/K}(𝔅) and β ≫ 0, so N(β) ≡ x² (mod p) and (N(β)/p) = 1.
   - So Φ(c), which contains N_{E/k2}(𝔅) of norm N(β), lies in the genus where χ_{−p} = 1, the principal genus.
   - |A| = h(−8p)/2. By genus theory, −8p has 2 genera and the principal genus is Cl² (IMPORTED). So Φ is onto Cl². This proves (a).
4. **Local lifting.** Let γ₁ be counted by N_E. Then {N_{E/k2}(𝔅) : 𝔅𝔅̄ = γ₁O_E} = {ideals of O_{k2} of norm N(γ₁)}, checked prime by prime with the factorization of Lemma 11.2:
   - q split in K, (−2/q) = 1: the primes 𝔔, 𝔔^ρ of E above 𝔮 map to the two conjugate primes of k2 above q, so the choices 𝔔^b(𝔔^ρ)^{a−b} give all ideals of norm q^a.
   - (−2/q) = −1: a is even and q is inert in k2.
   - q = 2: 𝔭O_E = 𝔓², and N_{E/k2}𝔓 is the ramified prime of k2 over 2.
   - q = p, with 𝔡 | γ₁ only if (−2/p) = 1: 𝔡 = 𝔇𝔇^ρ, both mapping to the ramified prime of k2 over p.
5. **Proof of (b).**
   - If 𝔅 ∈ c has 𝔅𝔅̄ = γ₁O_E, then Φ(c) contains an ideal of norm N(γ₁), so f = Φ(c) represents N(γ₁).
   - Conversely, if Φ(c) contains such an ideal, step 4 writes it as N_{E/k2}(𝔅) with 𝔅𝔅̄ = γ₁O_E. Then [𝔅] ∈ A and Φ([𝔅]) = Φ(c), so [𝔅] = c.
   - The dictionary "a class contains an ideal of norm n ⇔ the form represents n" is standard. The set of such classes is closed under inversion (conjugate ideals), as is the set of integers a form represents.
6. **Proof of (c).** By step 4 every class containing an ideal of norm N(γ₁) is some Φ([𝔅]). ∎

Checks (CERTIFIED):
- The multisets agree exactly with the PARI class distribution for 50 sampled primes ≤ 20000 (`test_nu_equals_pari_class_distribution`).
- ν*(p) = max_c n(c) (PARI) for **all 4808 primes p ≡ 3 mod 4, p ≤ 10^5** (data/r2_scan*.jsonl vs data/r3_scan_1e6).
- ν vanishes off the principal genus in all sampled fields.
- For composite D (h(K) even) Φ is not injective. There ν only bounds n from above, and the R2 PARI scan remains the tool.

*Note on (b).* The union over the members of a square class matters: γ₁ and γ₁ξ² can have different norms, and taking one representative per class undercounts (first implementation; caught by the PARI comparison).

**Corollary 11.4 (PROVED; the certificate).** Let p ≡ 3 (mod 4) be prime and f ∈ Cl(−8p)² with ν(f) = ν*(p).
- Take g with g² = f. If h(−8p)/2 is odd, g = f^{(h/2+1)/2}.
- Take an ideal 𝔟 = [a, −b/2 + √−2p] in the class g, where g = (a, b, c).
- Then M := (𝔟O_E, N_{E/K}/a), i.e. Q(x + y√−2) = (x² + 2y²)/a on a rank-4 Z-lattice in K², is a classically integral binary O_K-lattice with s□(M) = ν*(p).

*Proof.*
- N_{E/K}(𝔟O_E) = N(𝔟)O_K = aO_K, so Theorem 10.2(a) gives integrality.
- c := j_{k2}(g) = [𝔟O_E] lies in A: its norm to K is generated by a rational number > 0.
- Φ(c) = g² = f.
- Theorem 10.2(c) gives s□(M) = n(c^{−1}) = n(c) = ν(f). ∎

`scripts/certify_form.py` builds M in pure Python and finds vectors only on the edges that carry a represented class. Each value γ comes with its edge functional δ (δ ≫ 0, Tr(δO) ⊆ Z, Tr(δγ) = 1), which certifies indecomposability: γ = β + β′ with β, β′ ≫ 0 would give Tr(δγ) ≥ 2. It costs 25 s at p = 98179, where the R2 route needs a PARI bnf and an edge-by-edge search taking minutes.

## 3. Algorithm and cost
Per prime p, all in pure Python (PARI only for h(−8p) via `qfbclassno(·,1)`; `h_neg` counts reduced forms as a cross-check):
1. CF of √p, and the ι norms (Lemma 11.0).
2. Exact square classes of the 2ι elements {β, 2β} (= {β, βε} mod squares under (H)).
   - Separated first by squarefree norm and by 8 quadratic characters at degree-1 primes ℓ > 4p. All of these are square-class invariants.
   - Pairs with equal signatures are then compared exactly (`same_square_class` on big integers).
   - κ□ agrees with `FieldData` on 156 fields.
3. ν(f) from the classes of ideals of norm N(γ₁) in Cl(−8p) (Gauss composition of prime forms), taking the union over the members of each square class.

Cost: 0.2 s at p ≈ 10^5 and ≈ 20 s at p ≈ 10^7, against minutes to hours for the PARI bnf route. The CF-only proxy ι/√p costs ≈ 1 ms per prime.

**What drives ν*.**
- **Fits.** On p ∈ (10^5, 10^6] with x > ½ (32733 fields), least squares give:
  - log avg = 1.40 + 0.85·log x − 0.18·log L₈ (R² = 0.976);
  - log ν* = 0.59·log x + 0.98·log log p − 0.04·log L₈ + const (R² = 0.84).
- **The average** is essentially proportional to ι/√p: corr(avg, x) = 0.97, and avg/x = 3.34 ± 0.55.
- **The pigeonhole proxy** 2N_E/h(−8p) correlates only 0.60 with x. The multiplicity of Lemma 11.2 is essential.
- **The max/average ratio** grows slowly: 2.6, 3.3, 3.7 on the decades 10^3, 10^4, 10^5.
- So ν* ≈ (ι/√p)^{0.6}·log p, roughly.

**Heuristic (HEURISTIC; the gaps are (G1), (G2) of §5).**
- Σ_c n(c) ≈ Σ_{γ} Σ_{m|N(γ)} χ_{−8}(m), the near-injectivity of 𝔅 ↦ class.
- The norms are values (p − u²)/Q of quadratic polynomials of discriminant 4p (Lemma 11.0). Hence the local densities give mean Σ_m χ_{−8}(m)ρ(m)/m ≈ L(1, χ_{−8})·L(1, χ_{−8p}), with ρ(q) = 1 + (p/q).
- Dividing by |A| = h(−8p)/2 ≍ √p·L(1, χ_{−8p}) leaves avg ≍ ι/√p.
- The cancellation is only partial in the data (exponent −0.18 of L₈). The divisor sums are truncated at the size of the norms (≤ p), so the Euler product for L(1, χ_{−8p}) is only partly realised.
- For h(Q(√p)) = 1, Proposition 11.5(c) gives ι/√p ≈ T(p)/(4√p) ≍ log p·L(1, χ_{4p}). This matches the observed linear growth of the mean in ln p.

## 5. What a proof of growth needs (the honest status of R3)
**Proposition 11.5 (PROVED).** For p ≡ 3 (mod 4) prime:
- (a) **Upper bound.** ν*(p) ≤ min(12s, N_E(p)) and N_E(p) ≤ κ□ ≤ 2ι. So a family with ν* → ∞ must have s → ∞ (L1.5). In particular, every bounded-period family (Richaud–Degert, D = n² + 2, any prescribed-palindrome family with a fixed palindrome) has bounded ν*.
- (b) **Unconditional pigeonhole.** ν*(p) ≥ 2N_E(p)/h(−8p) ≥ 2π·N_E(p)/(√(8p)·(log 8p + 2)).
  - Uses h(−8p) = √(8p)·L(1, χ_{−8p})/π and the elementary L(1, χ) ≤ log q + 2.
  - So ν* → ∞ along any sequence of primes with N_E(p)/(√p log p) → ∞.
- (c) **Size of ι when h(Q(√p)) = 1.** ι(p) = T(p)/4 − (3/2)·h(−p), with T(p) = Σ_{|u|<√p} d(p − u²). This follows from the IMPORTED identities of Zagier and Hirzebruch, CERTIFIED for all h = 1 primes ≤ 10^6.

*Proof.* (a) Theorem 11.3 and L1.5. (b) Theorem 11.1(c). (c) Write ι = Σ a_odd. Zagier's identity gives Σ a_odd + Σ a_even = T/2, and Hirzebruch's gives Σ a_even − Σ a_odd = 3h(−p). ∎

**Why (b) does not close the argument.**
- N_E ≤ 2ι ≤ T(p) ≪ √p·log p·L(1, χ_{4p}), so (b) needs N_E within a bounded factor of its largest possible size.
- But only a fraction of order (log p)^{−1/4} of the norms is represented by x² + 2y² (heuristic: each prime factor of N(γ) splits in Q(√p) and is ≡ 1, 3 mod 8 with probability ½).
- The bound h(−8p) ≪ √p·log p also loses the factor L(1, χ_{−8p}).
- §4 shows what actually happens: the average of n(c) is ≈ C·ι/√p. The multiplicity Σ_{m|N(γ)} χ_{−8}(m) of Lemma 11.2 makes up the (log p)^{−1/4}, and its mean value is ∝ L(1, χ_{−8p}), which cancels h(−8p).

So a proof of ν*(p) → ∞ along infinitely many p needs two inputs. Neither is available.

**(G1) Long principal cycle.** Infinitely many primes p with ι(p)/√p → ∞.
- By (c) this holds for primes with h(Q(√p)) = 1, as soon as L(1, χ_{4p})·log p is large compared with L(1, χ_{−p}). That is true for all but a sparse set of p.
- But infinitely many p with h(Q(√p)) = 1 is Gauss's class number one problem for real quadratic fields: OPEN, even under GRH.
- Without h = 1, nothing bounds ι from below by T/h⁺: the principal Zagier cycle is a single class.
- We know of no explicit infinite family with ι/√D → ∞. The bounded-period families have ι ≍ √D at best (D = n² + 2: ι = n). Prescribed-palindrome families (Friesen, Halter-Koch) keep ι fixed while D → ∞ (the free parameter is a_0, which enters only a_s = 2a_0, an even index), so ι/√D → 0.

**(G2) Equidistribution / mean value.** A lower bound Σ_{(j,t)} Σ_{m | N(β_{j,t})} χ_{−8}(m) ≫ ι·L(1, χ_{−8p}) for the twisted divisor function on the norms (p − u²)/Q_{j+1} along the principal cycle (Lemma 11.0).
- With this, avg n(c) ≫ ι/√p, by Theorem 11.1(c) and the near-injectivity of 𝔅 ↦ class.
- For h(Q(√p)) = 1 the principal cycle is half of all forms of discriminant 4p with ac < 0. But the indecomposables are the ι-part of that half (the even-indexed ι′-part is the other), and this split is not a congruence condition. So (G2) is a shifted-convolution problem with no known unconditional treatment in the needed uniformity (the range of u is ≍ √(values)).

**Conclusion (R3).**
- Under (G1) + (G2), S(Q(√p),2) ≥ ν*(p) → ∞ along those p, and the growth rate of the heuristic is ν* ≍ ι/√p, which is ≍ log p on h = 1 primes.
- Unconditionally we have only the exact model (Theorem 11.3) and certified records (§6).
- The dichotomy L5.2 stays OPEN. The governing invariant is ι(p)/√p (the length of the principal Zagier cycle against √p), not s and not h(E).
