## 1. The Thm 22 table (CERTIFIED; `python3 scripts/r4_thm22.py out.jsonl`)

**Re-run.** A unit-determinant frame is Ov + Ow with α = Q(v), β = Q(w) indecomposable in distinct square classes and det = αβ − b² ∈ O^{×,+}.
- Such a frame is unimodular, so it has no proper integral overlattice. The restricted maximum is therefore max s□(frame).
- We enumerate the frames with R1's provably complete enumeration (`complete.frames`, all frames up to symmetry) and evaluate each exactly (`complete.evaluate`).

**Results.**
- **"No unit-determinant frame" means no non-trivial one.** In every field of the "none" list the only unit-determinant frame is the diagonal ⟨1, ε⟩ (α = 1, β = ε, b = 0, two units, s□ = 2). It exists whenever N(ε) = +1. With that frame excluded, the "none" list is reproduced exactly: these 11 fields have no other unit-determinant frame.
- **Values.** All values are reproduced, and D = 31 is exactly 4, except **D = 22**. There the frame α = 5 − √22, β = 61 − 13√22, b = −14 + 3√22 has det = 197 − 42√22 = ε^{−1} and represents the 4 classes [5 ± √22], [61 ± 13√22], all of norm 3. These are indecomposable and pairwise distinct mod K^{×2}, checked exactly. So the imported "2–3" is wrong (C26). The value 4 is also the complete S(Q(√22),2).

## 2. Thm 4 — Ramsey reduction (PROVED; reconstruction)
**Statement (reconstructed).**
- Let K be totally real of degree d, and let γ₁, …, γ_N be pairwise distinct indecomposables, for instance one per class represented by a lattice M.
- If N ≥ R_{d(d−1)}(k), the d(d−1)-colour Ramsey number, then there are places i ≠ j and k of the γ's which, in a suitable order, are strictly decreasing at σ_i and strictly increasing at σ_j: a *two-place staircase*.

**Proof.**
- For distinct indecomposables α ≠ β, the difference α − β is not totally positive: otherwise α = β + (α − β) decomposes. By symmetry it is not totally negative either. And it is ≠ 0 at every place, since α ≠ β and all embeddings of a nonzero element are nonzero.
- So there are places i, j with σ_i(α) > σ_i(β) and σ_j(α) < σ_j(β).
- Colour each pair a < b (in a fixed labelling) by such an ordered pair (i, j); there are d(d−1) colours.
- Ramsey's theorem gives a monochromatic k-subset, which is the staircase. ∎

**Assessment.**
- The lattice M plays no role: the statement is about indecomposables only.
- For d = 2 it is empty. Any two distinct indecomposables of a real quadratic field are already in "staircase" position (opposite order at the two places), so every set of them is a staircase.
- The motivation in 01_problem — "a large s□ in any degree forces a two-place staircase, the configuration the real quadratic sail realizes, so real quadratic binary lattices are the irreducible core" — does not follow.
  - The staircase lives in K of degree d. Its projection to two places is not the sail of a real quadratic field, and the lattice/arithmetic constraints are lost.
  - The reduction gives no implication from the real quadratic case to degree d (C27; 01_problem updated).

## 3. Prop 5 — no minimum angle (PROVED)
**Statement.**
- For every δ > 0 there are a real quadratic field K, a classically integral, totally positive definite binary O_K-lattice M, and vectors v, w ∈ M such that:
  - Q(v), Q(w) are indecomposable in distinct classes mod K^{×2};
  - the trace angle satisfies cos∠_Tr(v, w) := Tr B(v,w)/√(Tr Q(v)·Tr Q(w)) > 1 − δ.

**Construction.**
- Field: n ≥ 6 even, D = n² + 2 squarefree, K = Q(√D), O = Z[√D] (D ≡ 2 mod 4).
- Continued fraction: √D = [n; \overline{n, 2n}], so the indecomposables mod units are γ_t = 1 + tμ for 0 ≤ t ≤ n − 1, where μ = n + √D, N(μ) = −2, μ² = 2ε and ε = n² + 1 + n√D (Lemma 11.0: N(γ_t) = 1 + 2tn − 2t²).
- Lattice: put t = n/2 − 1 and M = O² with Gram G = [[γ_t, tμ], [tμ, γ_{t+1}]], v = e₁, w = e₂.

**Proof.**
- *Integral and positive definite.*
  - The entries lie in O.
  - det G = γ_tγ_{t+1} − t²μ² = 1 + (2t+1)μ + 2tε.
  - At σ₁ every term is positive. At σ₂ we have μ′ = −2/(n + √D) and ε′ = 1/ε, so σ₂(det G) > 1 − 2(2t+1)/(n + √D) > 0, because 2t + 1 = n − 1 < (n + √D)/2.
  - Also σ₂(γ_t) = 1 − 2t/(n + √D) > 0.
- *Indecomposable.* t, t + 1 ≤ n − 1.
- *Distinct classes.*
  - N(γ_t) = (n² − 2)/2 and N(γ_{t+1}) = (n² + 2)/2 (u = 2, 0 in Lemma 11.0).
  - Their product (n⁴ − 4)/4 is not a rational square, because (n² − 1)² < n⁴ − 4 < (n²)² for n ≥ 2.
  - So γ_tγ_{t+1} ∉ K^{×2}, since its norm would otherwise be a square.
- *Angle.* With A = n²/2, Tr Q(v) = 2(A − n + 1), Tr Q(w) = 2(A + 1) and Tr B(v,w) = 2(A − n). So
  1 − cos² = (n³/2 − n + 1)/((A − n + 1)(A + 1)) ≤ (n³/2)/((A − n)A) = 2/(n − 2),
  hence 0 < 1 − cos ≤ 2/(n − 2).
- *Infinitely many n.* n² + 2 = 2(2m² + 1) with n = 2m is squarefree for infinitely many m. IMPORTED: an irreducible quadratic without fixed square divisor takes squarefree values with positive density (Estermann 1931; Ricci 1933). Squarefree for 57 of the 75 even n with 6 ≤ n ≤ 154, and all 57 pass the exact checks (`r4_checks.py prop5`). ∎

Checked exactly for even n ≤ 100 (`test_prop5_family`): 1 − cos = 0.24, 0.10, 0.036, 0.0103 at n = 6, 12, 30, 100.
- At the second place the two vectors become nearly opposite: cos at σ₂ = −0.56, −0.77, −0.90, −0.97 at n = 6, 12, 30, 100, tending to −1. This matches the imported summary "separation only at a pair-dependent place".
- Consequence (already recorded as L3.3, now PROVED): there is no uniform minimum trace angle between vectors representing distinct indecomposable classes, so spherical-code bounds in the trace form cannot bound s□.

## 4. Thm 17 — regulator ceiling, and Cor 21.3
**Imported statement (L1.6).** s□(M) ≤ V₂^d·2^{d−1}·Reg(K)/√N(𝔳M) + E, described as a "volume count of vectors with N(Q(u)) ≤ Δ modulo units".
- E is not specified.
- Main term. Take d = 2 and M free with Gram G. The region {u ∈ (R²)² : Q₁(u₁)Q₂(u₂) ≤ X} modulo u ↦ εu has volume 2π²·X·Reg/√N(det G). Dividing by covol(O²) = Δ, putting X = Δ/4 and identifying ±u gives a heuristic count ≈ (π²/4)·Reg/√N(𝔳M). So the main term has the right shape.
- Error term. The fundamental domain is a hyperbolic sector elongated by a factor ε², so the lattice-point error is not small. Without an explicit E the statement has no content. It is **UNUSABLE as stated**; nothing in the repository depends on it.

**What is true (PROVED).** For every real quadratic K and every integral binary M:
  s□(M) ≤ 12s ≤ 24 + (12/log φ)·(Reg(K) − log(√D − 1)) < 24 + 24.94·Reg(K),
with φ = (1 + √5)/2 and Reg = log ε.
- *Proof.*
  - The first inequality is L1.5.
  - The fundamental unit is ε = p_{s−1} − q_{s−1}ω′, where p_k/q_k are the convergents of ω and ω′ < 0 is its conjugate.
  - Since p_k ≥ a₀q_k and a₀ ≥ ω − 1, we get ε ≥ q_{s−1}(ω − 1 − ω′) = q_{s−1}(√D − 1).
  - From q_k = a_kq_{k−1} + q_{k−2} with q₀ = 1, q₁ = a₁ ≥ 1, we get q_k ≥ F_{k+1}, the Fibonacci numbers. Hence q_{s−1} ≥ F_s ≥ φ^{s−2}.
  - So log ε ≥ (s − 2)·log φ + log(√D − 1). ∎
- Checked for all squarefree D ≤ 5000 (`test_regulator_inequality`).
- The volume factor 1/√N(𝔳M) is plausible as a main term but OPEN. It is irrelevant to boundedness of S(K,2): unimodular lattices have N(𝔳M) = 1, and since Reg ≥ (s − 2) log φ, any bound C·Reg is weaker than 12s up to constants.

**Cor 21.3 (imported).** Along D = t² + 1, the proportion of indecomposable classes γ with αγ a norm from E = K(√−ε⁺) tends to 0. Here N(ε) = −1, so ε⁺ = ε² and E = K(i).
- *Lattice form (PROVED).* s = 1, so S(K,2) ≤ 12 (L1.5), while κ□(K) ≥ t^{1−o(1)} → ∞. Hence s□(M)/κ□ ≤ 12/κ□ → 0 for every M.
  - Proof of the κ□ bound. Here √D = [t; \overline{2t}] and ε = t + √D. The semiconvergents 1 + kε, 0 ≤ k ≤ 2t, are indecomposable, with N(1 + kε) = 1 + 2kt − k² = D − (t − k)². So u = t − k gives the t + 1 distinct norms D − u², 0 ≤ u ≤ t. If only m squarefree parts c occurred, each equation u² + c·y² = D (positive definite) would have ≤ 6·d(D) solutions: u + y√−c is an element of norm D in the ring of integers of Q(√−c), there are ≤ d(D) ideals of norm D, and ≤ 6 generators per ideal. So t + 1 ≤ 6m·d(D), i.e. m ≥ t^{1−o(1)}, and κ□ ≥ m.
- *Norm form.* For t odd and α = 1, γ is a norm from K(i) iff N(γ) is a sum of two squares (as in Lemma 11.2, with χ₋₄; 2 is ramified in K).
  - EMPIRICAL: the proportion of the 2t indecomposables mod units with this property is 0.59, 0.48, 0.41, 0.37, 0.34, 0.32 on t ∈ [3,30), …, [3000, 6000), i.e. ≈ 1.35/√log D (`r4_checks.py cor213 6001`).
  - HEURISTIC: an upper-bound sieve of dimension ½ gives ≪ 1/√log t times a factor ∏_{q≡3(4), q ≤ z}(1 + χ_D(q)/q)^{±1}.
  - Gap: that factor is not controlled uniformly in t without GRH-type input.
  - It is not needed anywhere, since the lattice form holds trivially.
